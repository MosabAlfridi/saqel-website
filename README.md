# صقل — AI Capacity Initiative

Single-page site for صقل, a non-profit initiative building AI capability among youth in Hail, Saudi Arabia.

Arabic-first (RTL), dark brand theme, no build step. Open `index.html` directly or serve the folder.

## Files

- `index.html` — the whole page. Tailwind and Readex Pro load from CDN.
- `assets/logo.svg`, `logo-white.svg`, `favicon.svg` — brand mark, vector.
- `assets/*.jpg` — event photography.
- `assets/hail-landscape.jpg` — Al Nefud dunes and the granite of Aja, Naylat, Hail.
  Photo by Rabah Al Shammary via Unsplash (Unsplash License).
  https://unsplash.com/photos/7vOpzRF33Zo
